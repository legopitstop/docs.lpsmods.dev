# Frequently Asked Questions

Below are answers to questions you might have.

## What is `@lpsmods/docs-generator`?

`@lpsmods/docs-generator` is a package for generating Markdown API documentation from source files using Tree-sitter grammars, providing:

- PyPI and NPMjs registry
- Multiple ready to use templates.
- Easy to use CLI

## How do I report bugs or request features?

You can submit a bug report or feature request via the [GitHub Repository](https://github.com/lpsmods/docs-generator/issues)

## How do I contribute?

See the [CONTRIBUTING.md](https://github.com/lpsmods/docs-generator/blob/main/CONTRIBUTING.md) file for more information about contributing.

## What versions of the scripting API are supported?

`@lpsmods/docs-generator` will always support the latest scripting API version and will not work for older versions.
